## Lesson 1.1: Statements and the structure of a program
* Statements: A statement is a type of instruction that causes the program to perform some action.
* Functions : A function is a collection of statements that get executed sequentially (in order,     from top to bottom). Every C++ program must have a special function named main (all lower case     letters).
* Characters: A character is a written symbol or mark, such as a letter, digit, punctuation mark,    or mathematical symbol.
* Text: A sequence of characters is called text (also called a string in programming contexts).
* Syntax: The set of rules that describe how specific words (and punctuation) can be arranged to     form valid sentences in a language is called syntax.
